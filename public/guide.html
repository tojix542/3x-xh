Site Guide

Everything you need to know about using 3x Forensics — from authentication to scan interpretation.

1 Getting Started
Step 1 Authenticate with Discord
Click "Continue with Discord" on the auth page. You must have the Customer role in the controller guild to access the dashboard. If you don't have the role, contact the owner.
💡
Tip: Make sure you're logged into the correct Discord account before clicking. The auth flow will use your current Discord session.
Step 2 Download the Desktop Agent
From the Dashboard, click "Download 3x-Agent.ps1". This PowerShell script runs on the target Windows machine and collects forensic data. The agent runs with a hidden console and shows a loading UI until complete.
powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File .x-agent.ps1 -ApiUrl "https://your-domain.com"
Step 3 Run the Agent on Target PC
Transfer the agent to the target machine and run it. The agent will display a loading window while collecting data. Once complete, it automatically submits the report to the 3x server and shows results in your browser.
⚠️
Important: The agent requires Administrator privileges. Right-click PowerShell and select "Run as Administrator" before executing.
2 Understanding Scan Results
Risk Score 0-100 Scale
The risk score aggregates findings across all modules. Lower is better. Scores above 50 indicate critical artifacts detected.
0-14Clean — No suspicious activity
15-49Warning — Low-risk artifacts found
50-100Critical — Evasion techniques detected
100+Severe — Multiple cheat indicators

3 Limitations & Rules
Critical Scan Limits
Each customer is limited to 2 scans per 24-hour period. Exceeding this triggers an automatic ban. Self-scanning is also detected and banned instantly. Review the Rules of Use for full details.
Agent Windows-Only
The 3x Agent currently supports Windows 10 and Windows 11 only. macOS and Linux are not supported. The agent requires PowerShell 5.1 or later.
4 Troubleshooting
Issue "Access Denied" on Agent
Run PowerShell as Administrator. Right-click the PowerShell icon and select "Run as Administrator" before executing the agent script.
Issue "Customer Role Not Found"
You need the Customer role in the controller Discord server. Contact the owner to get the role assigned. Your Discord ID is logged automatically.
Issue Scan Results Not Showing
Ensure the agent's -ApiUrl parameter matches your site's URL. If running locally, use http://localhost:3000. Check the browser console for API errors.
